## Integrated Android source change

[Production instrumentation](../scripts/instrument_android_runtime_operations.py) now adds **Android-only** `AndroidRuntimeLog.Write("save", "Load.caughtException", ...)` upon entry to the single authenticated original `Load<T>` catch handler, **after the adapted-source SHA guard** and only if the source manifest includes the original `Load<T>` signature. The original Load method body, Deserialize call, catch handling, return, exceptions, save paths, world flags, original GUIDs, and `.rgd` data are preserved aside from that inserted log line. A repeated/unknown catch, unknown original source or duplicate injection fails closed. This fills a diagnostic gap: the pre-existing outer operation wrapper may not see an exception internally handled by the original loader.
