# مختبر Android الاختياري لـ RAFT

## متى وكيف تستخدمه
- الفرع العامل حرّ في إجراء اختباره بنفسه أو استخدام المختبر أو مقارنة نتائج المسارين. لا توجد كلمة تفعيل أو مطالبة بالانتظار. يستمر المختبر بتجارب مستقلة مفيدة ويشارك الدليل، ولا يكتب على فرع الاستعادة ولا ينقل إليه الـworkflow.
- ابدأ من رأس المختبر الحالي واقرأ README والـworkflow. للاختبار الجديد اعمل على `qa/android-emulator` فقط: مدخل اصطناعي صغير، خطوات ADB محددة، وبكسلات أو سجلات قابلة للمراجعة. دفع تحديث ذي صلة إلى الفرع يشغّل الاختبار؛ لإعادة الحالة نفسها استخدم إعادة تشغيل المهمة القائمة إن كانت متاحة. لا تُنشئ تعديلاً وهمياً، ولا تنقل الـworkflow إلى الفرع الافتراضي لتفعيل زر التشغيل اليدوي.
- اضبط فرضية واضحة لكل تجربة (مثل تغيّر لون، قراءة بكسل أو ظهور مشكلة عند حدث محدد). شارك SHA المصدر، رابط الـjob، ABI/إصدار النظام، مزوّد الرسم، خطوات إعادة الاختبار، وما أثبته أو لم يثبته. اقرأ نتيجة كل job بدل حالة المصفوفة كلها، وراجع بصمة الأثر قبل استخدامه. فيديو ولقطات بحسب الحاجة والنتائج المثبتة في README؛ لا تُنشر مواد خاصة أو أسرار.
- نسخة RAFT قديمة ومأذونة فقط إذا كانت الحاجة واضحة: استخدم ناتجاً موجوداً مع مصدر وبصمة، وتحقق من ABI والتوقيع وملفات base/splits، ثم سجّل ما حصل فعلياً. لا تُنشئ XAPK جديداً للتشخيص، ولا ترفع ملفات اللعبة أو بياناتها الخاصة إلى آثار عامة.

## الدليل وحدوده
- x86_64 / Android API 35 / KVM: إقلاع وتثبيت APK اصطناعي وتشغيله، نقرة ADB، لقطتان مع تحقق البكسلات، GLES عبر SwiftShader. [محاولة أولى](https://github.com/alwansan/raf/actions/runs/46167315368/job/141047613556) و[ثانية](https://github.com/alwansan/raf/actions/runs/46167315368/job/141052880961).
- Vulkan داخل المحاكي: تنفيذ نقل وقراءة 32 بكسلاً عبر SwiftShader في [محاولتين مستقلتين](https://github.com/alwansan/raf/actions/runs/46170824751/attempts/2)، منها [المهمة الأولى](https://github.com/alwansan/raf/actions/runs/46170824751/job/141058637544) و[المهمة الثانية](https://github.com/alwansan/raf/actions/runs/46170824751/job/141064729911). هذا ليس إثبات مسار شيدر Vulkan أو عرض RAFT الفعلي.
- [ARM64 الأصلي لم يعمل](https://github.com/alwansan/raf/actions/runs/46170824751/job/141058637828) في المشغّل المختبَر لغياب SDK وKVM. إعلان دعم ABI أو ترجمة محتملة داخل x86_64 لا يُعدّ تنفيذ ARM64 أصلياً. لا استنتاج عن GPU الهاتف أو جودة رسوم اللعبة من النتائج الاصطناعية.
- لا تغيير لشروط G0–G6 أو الاستعادة أو إنتاج XAPK؛ المختبر أداة فرز وتشخيص، وليس بديل اختبار الهاتف.
