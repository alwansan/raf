- requires an externally supplied SHA and separately produced bounded numeric authentic-staging report, original Foam ShaderLab identity, *exactly two* pass bodies with complete programs, four program-stage claims, authored two-properties shape, exact original stage model boolean, no false Unity/Android claims;
- rejects invalid/multiple exported Foam shader identities, redirected symlink parent/file, missing/multiple/malformed original GUID sidecars, in-project or existing backup directories;
- writes an fsynced external original shader + byte-exact `.meta` backup before replacing only the unique exported source using atomic fsync/rename; verifies the original metadata is unchanged;
- attempts atomic original byte restore if post-promotion verification fails, preserving the verified external backup if rollback itself fails. It never alters protected source assets or publishes private ShaderLab.
