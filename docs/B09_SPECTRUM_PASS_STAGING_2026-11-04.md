# B09 — original Spectrum pass-stage recovery staging (4 November 2026)

## Why this work exists
APK86 ([real game delivery 41812889049](https://github.com/alwansan/raf/actions/runs/41812889049)) still reports `UltimateWater/Spectrum/Water Spectrum` as one exported ShaderLab pass when the device requested at least six. W4's [native diagnostic](https://github.com/alwansan/raf/actions/runs/41808015938) independently found Spectrum 1/6, Foam 1/2, Blur 1/2, and no authentic water compute source in the resulting export. B45 is working Blur and B24 Foam; B09 selected Spectrum rather than duplicating those efforts. A source-aware pass count alone does not reconstruct any original shader program.

## Committed engineering changes
- [Original pass-stage extractor](https://github.com/alwansan/raf/commit/7ee586f3749913e6c02fa2e2763656f860fe2e97): `scripts/b09_stage_original_spectrum.py`. It authenticates only the two SHA-pinned ZIP2 graphics owners, locates exactly one original serialized Spectrum Shader, requires at least the six observed passes and an original D3D11 table, then uses existing validated DXBC record decoding and stage checks. It stages **every exact vertex/fragment variant pair by permutation key rather than array position** in an isolated temporary path. Duplicates, missing programs, stage misidentification, nonnormal passes and unmatched permutations fail closed. All stage files are hashed and reread; the only allowed public report contains numeric indices/counts/hashes, not program bytes, original property names or private HLSL.
- [Bounded tests](https://github.com/alwansan/raf/commit/5511675ccda4c39ac68c4a8c48f257e65bdcef56): `tests/test_b09_stage_original_spectrum.py`. **10/10 local synthetic tests passed**, including out-of-order original variants, mismatched/duplicate/missing stages, unsafe symlink rejection and no DXBC in report. This does not prove original shader parse or real pixel results.
- [Targeted original-data CI workflow](https://github.com/alwansan/raf/commit/5256ac018f7f2da932a34938e99fbb27cca2f1f0): `.github/workflows/raft-b09-spectrum-extraction.yml`, isolated concurrency (no cancellation), 30-minute timeout, only original resources.assets and sharedassets0.assets restored from pinned ZIP2 SHA `15964ea8f246b6e076ce26b60931ee2e1a9a2385` into scratch. Expected original bytes/hashes: `111533516/87493249f1adfc0c5eb8b82e4e199e208cd2c95eabe9796cab82116c4838595c`; `115978112/0498f738dc86e90ebfb2c29da6860ba74e5f81de727ff279d419497c1628a3c3`. It runs the source-staging method and deletes private DXBC before uploading **only** the JSON aggregate.
