## What was genuinely executed
[`android-port/Experiments/T4/OriginalManagedStreamRoundtrip/Program.cs`](../android-port/Experiments/T4/OriginalManagedStreamRoundtrip/Program.cs) privately:
1. Verified original immutable game DLL bytes/SHA, resolved `SaveAndLoad`'s two **actual compiled** FileManager call operands and enforced no unknown try-path calls.
2. Created a new, unique process-owned temporary directory, **not** the user's Android/game save directory, and an intentionally **synthetic** filename ending in `.rgd`. No real RGD schema, game object, player inventory or private saved payload was used.
3. Invoked original `FileManager` create method via reflection, checked that a writable file stream was returned, wrote fixed test bytes, flushed to disk and **disposed/closed** the stream.
4. Invoked original `FileManager` open method with `FileMode.Open`, checked readable stream, copied bytes to memory and closed it, comparing exact byte sequence and file size against the synthetic fixture.
5. Deleted the disposable directory before success, reported **only** boolean safe facts. Raw payload, original method names, private stack traces, dependency names and filesystem paths were never printed or uploaded.

[`scripts/t4_validate_original_managed_stream_roundtrip.py`](../scripts/t4_validate_original_managed_stream_roundtrip.py) and [15 fail-closed source-free cases](../tests/test_t4_validate_original_managed_stream_roundtrip.py) reject any report claiming a real game RGD serialization, Android app storage, Unity/IL2CPP execution or private original data publication, and require proof of exact original method invocation, stream closure, byte equality and cleanup.
