## Source, failure, and distinction
Client `raft-20261103T113735Z-a93e6c40` (A9) independently inspected [full native run 41624581951](https://github.com/alwansan/raf/actions/runs/41624581951), source c7254f7d, reconstruct job125878883840. This run FAILED before Unity at `restore_builtin_shaders.restore_project`: `No exported built-in shader identities matched; custom shaders cannot be substituted`. Authentic Unity 2021.3.45f2 shader archive source verification reported 198 known shaders, but the actual export's declarations were **not** classified in that failed run. Do not confuse missing exported matches with a demonstrated C# or Vulkan shader implementation issue.

The baseline `restore_project` used the broad `DECL.search` expression and could classify `/* Shader "Standard" */` or `// Shader "Legacy"` as an executable exported ShaderLab name. A custom shader with a commented built-in header could therefore be **overwritten** with an unrelated vendor shader while its original .meta retained. This was reproduced with synthetic project files; there is no evidence this specific comment was present in the actual earlier private export.
