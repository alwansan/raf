### Follow-up work in the logger
- Reduce logcat-to-Binder calls by batching larger payloads, while preserving the complete raw stream and flushing small idle batches.
- Add sampled game log line rate in lines/sec, plus a warning when exceeding 10,000 lines/sec.
- Capture a presentation progress age and heuristic sustained-frame-stall flag; add frame pacing percentiles derived from external presentation timestamps.
- Add a low-system-available-memory indicator. Neither a log rate flag nor low-available-RAM flag is an official Android kill reason.
- Session metadata should reflect actual APK version, not a hard-coded old version.
- Keep the permanent **public test** signing identity unchanged so APK upgrades stay compatible.
- For real root-cause remediation, investigate the Raft game branch shader/pass/kernel errors and Unity/graphics thread contention. This repository logger branch alone cannot fix Unity rendering.

No Android 15 live-device verification of the *new* changes has yet occurred; GitHub Actions only validates build and signing.
