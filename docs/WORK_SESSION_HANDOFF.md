## 3. Tools, source reconstruction and verified milestones

- GitHub Actions Ubuntu runner is pinned to **`ubuntu-24.04`** because the migration of `ubuntu-latest` to 26.04 could break Unity 2021. See https://github.com/actions/runner-images/issues/14748 and `.github/workflows/raft-runner-compat-guard.yml`.
- Unity export: **AssetRipperCLI v1.0.1** from https://github.com/nowl-it/AssetRipperCLI/releases/download/v1.0.1/AssetRipper_linux_x64.zip with pinned SHA256 check. No executing Windows game binaries.
- Mono decompilation: **ILSpyCmd 11.2.0.10050** from CI `dotnet tool install`, specifically `-p -lv CSharp9_0`. Original ILSpy recovered **2,394 C# files**, roughly 251,725 lines. **NEVER revert to ILSpy Latest**: its C#10 file-scoped namespaces and C#12 struct primary constructors broke Unity 2021 parser.
- `scripts/overlay_ilspy_gameplay.py` replaces ~**1,568** AssetRipper generated gameplay stubs with matching real ILSpy source contents, keeping existing `.cs.meta` GUIDs. `scripts/supplement_ilspy_gameplay.py` appended **614 additional missing real helper files**; current reconstructed ephemeral project is about **4,425 C# sources** with **64,642/64,642** scene script GUID links.
- `scripts/normalize_csharp_namespaces.py` provides an extra syntax-compatibility guard. `scripts/repair_assetripper_stub_classnames.py` repairs **79 invalid autogenerated class names** and two generated Timeline collision placeholders via `--repair-timeline`, keeping GUIDs unchanged. **These are compile-diagnostic repairs, not full replacement runtime code**.
- `rea-agents@6.8.0` from https://github.com/morluto/rea ran successfully with Node.js v24.22.2; verified metadata, P/Invoke, network/save call graphs. It did *not* rebuild a Unity project. Other useful tools: dnfile, UnityPy, .NET/ILSpy; JADX is for Android DEX and not immediately relevant to this Mono PC build. User previously supplied REA/Node/JADX archives, but independent CI downloads worked; avoid asking for a reupload.
- Original recovered Mono C# .NET 8 **diagnostic-only** compilation succeeded (with old BinaryFormatter diagnostics suppressed); this is not real Unity or Android compilation and is not proof that BinaryFormatter is safe.
- The Android offline adapter in `android-port/Runtime/Platform` contains `LocalProfileStore.cs`, `LocalSavePaths.cs`, `OfflineSession.cs` and `UnityOfflinePlatformBootstrap.cs`. It compiled under netstandard2.1 and passed **7/7 tests** [41029669318](https://github.com/alwansan/raf/actions/runs/41029669318), **but is not integrated into the original Raft scenes/SteamManager/SaveAndLoad yet**.
