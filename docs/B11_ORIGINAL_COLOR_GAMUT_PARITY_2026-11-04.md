A *separate public Unity ProjectSettings YAML example* confirms the one-element gamut is serialized `m_ColorGamuts: 00000000`: https://d3axxy9bcycpv7.cloudfront.net/openai/orrb/src/main/unity/ProjectSettings/ProjectSettings.asset.html . **This external example is format support, not a Raft export capture**.

New [B11 guarded adapter](../scripts/b11_restore_original_color_gamuts.py) reuses B04's exact source SHA/size/version/original-gamut verifier before any edit, accepts only one bounded 8-hex-digit serialized gamut on one PlayerSettings document, and allows two known alternate one-element enums `01000000`/`02000000` to be corrected to `00000000`. It rejects unknown arrays, extra bytes, unknown enum, ambiguous fields, malformed UTF-8, NUL and symlinks/hardlinks. The only allowed edit is inside those **8 ASCII characters**, written atomically with concurrent-file integrity check. It preserves all other ProjectSettings bytes, original files, .meta/GUIDs, textures, materials, settings UI, FMOD and touch behavior.

Production integration [b26b942f](https://github.com/alwansan/raf/commit/b26b942f2f054c32091c628177835cdc68594cda) calls B11 immediately after B04 in the existing temporary export, then rechecks the copied `unity-candidate` read-only just before Unity.
