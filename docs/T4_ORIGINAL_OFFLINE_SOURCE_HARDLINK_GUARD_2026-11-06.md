# T4 LOCAL-005 — protect original offline source and .meta hardlink inodes

**6 November 2026.** T4, `origin=chat`, session `20261106T1801Z-T4-chat-offline-hardlink-safety-c7m3`; sole writable branch `feature/android-native-port`. This is an original source preservation / transaction safety repair in the local-world Android import, **not a gameplay world-host fix or game-save serialization change**.

## Reproduced mechanism

The original-source Android offline adapter `scripts/adapt_android_offline_startup.py::apply()` stages SHA-authenticated original `Assembly-CSharp/*.cs` and existing `.cs.meta` into a Unity project, backs up the originals and writes adapted source via `path.write_bytes(result)`. It checked symbolic links and redirected project/backup roots, but not the **hardlink count** of those original source/meta paths. On Linux two regular paths can share the exact same inode via a hardlink; overwriting a linked Unity staging file overwrites the supposedly original provider file outside the Unity project. This can poison a subsequent import/retry despite original SHA gates. The separate `scripts/adapt_original_save_paths.py` already rejects this same hardlink case, but `adapt_android_offline_startup.py` lacked parity.

This is a **possible ingestion condition** demonstrated using synthetic files; there is **no evidence ZIP2 or any actual original Raft file is currently hardlinked or corrupted**.

## Exact source-free red→green

The two new regression tests create a disposable synthetic `Settings.cs` with authentic adapter signature shape `SteamApps.GetAppBuildId()` and existing synthetic `.cs.meta`:
1. **Hardlinked source:** Unity `Settings.cs` and a file *outside* the project share an inode. The adapter must refuse the path before its backup/write stage and preserve external source bytes.
2. **Hardlinked GUID metadata:** Unity `Settings.cs.meta` and outside GUID metadata share an inode. Reject before source backup or mutation and leave both originals unchanged, even if the current adapter would only read the meta.
