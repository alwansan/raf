## 2. ما نعرفه عن الإضاءة
لم يُثبت بعد سبب مستقل لإضاءة العالم كلّه. أخطاء Subsurface Blur/VolumetricLight/Bloom القديمة تربك التأثيرات والـpost-processing، بينما غياب برامج PBR/vertex/fragment أو normal map قد يخفي أي استجابة للضوء أصلاً. رُفعت برامج Unity PostFX الرسمية سابقاً، لذلك لا نُعيد الجزم بأن Bloom نفسه ما زال ناقصاً في كل إصدار. أقرب اختبار حاسم: Mesh واحد، مادة أصلية معروفة، shader native المربوط فعلاً، ضوء اتجاهي معروف، ألبيدو/normal/emission منفصلة، مقارنة Linear vs sRGB وPass/Keywords/GPU API؛ دون إصلاح جماعي للإضاءة.

## 4. النتيجة الحالية
الأكثر إلحاحاً **استعادة برامج Shader الأصلية أو مكافئ موثق تحت نفس الهوية والـPass/variants/render state ثم اختبار Unity**؛ لا تُعالج المشكلة بالتلوين الافتراضي أو Gamma قسراً أو إعادة نسخ كل مواد اللعبة. كل تفسير pixel-level يبقى مشروطاً بتحقق runtime shader identity على نفس APK/scene. `RENDER-002/WATER-001 OPEN`, `NOT_READY 0/3`.
