## الملفات
- الذاكرة والحالة: ../clients/Bxx/state.json وMEMORY.md وsessions/<session_id>.md. لا تكتب ذاكرة أو شخصية عامل آخر.
- العمل: ../work/<issue>/Bxx-<session>-<work>.json قبل التنفيذ؛ التحديث عند البداية والتقدم والنهاية.
- التجارب: ../experiments/Bxx/<experiment_id>.json، نتائج موجزة مستديمة وروابط التشغيل والبصمات والأوامر.
