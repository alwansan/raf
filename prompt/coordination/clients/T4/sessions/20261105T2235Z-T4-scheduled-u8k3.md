## Source finding and fix

`ReleaseCapture()` increments the epoch on Unity's thread and schedules a UI-thread `releasePointerCapture` callback. Before this patch, an older queued release could run **after** a newer `RequestCapture()` and revoke that new capture. Added a captured `releaseEpoch` token and an early return if the epoch changed or a newer request is active. Existing request/probe epoch checks remain. This is a deterministic source-ordering fix, not a reproduced Android device incident.

Added regression policy assertion `test_stale_queued_release_cannot_revoke_new_capture` to verify release guard precedes Android release call. No changes to keyboard, touch, mouse buttons/wheel, UI/Resolution, game saves, scenes or assets.
