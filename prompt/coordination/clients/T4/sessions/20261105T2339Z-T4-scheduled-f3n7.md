## Independent finding / falsifiable hypothesis

If Android Unity 2021 Input System sees an attached hardware mouse while legacy Input.mousePresent is false, the conjunction suppresses requestPointerCapture even though a valid physical mouse exists. This is a code-level conditional, not proof that the mixed state occurs on the owner's phone. Avoid claiming a fix or Android success.
