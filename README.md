## الحالة

**NOT_READY — نسبة اكتمال اللعبة والسورس الكامل غير مقاسة.** النسب في اللوحة تخص جرداً محدداً فقط:40/40 مشهداً مصدّراً،17/17 سجل CanvasScaler،0/20 مطابقة صيغ FFT في فحص roundtrip موثّق،0/3 مراجعات جاهزية. هذه المقاييس مختلفة ولا يجوز جمعها في متوسط لاكتمال اللعبة.

اللوحة تعرض ستة مسارات قابلة للتوسيع، أدلتها وحدودها، تشغيلات Actions المقروءة والخطوات التالية. فشل preview41624581951 قبل Unity ما زال مختلفاً عن نجاح فحوص الإصلاح اللاحقة؛ الإصدار التاريخي APK80 ليس نتيجة HEAD الحالي.

## دورة تحديث up

1. اقرأ التعليمات والذاكرة ثم المصدر الحي وActions والإصدارات والعملاء.
2. حدّث data.json بروابط الأدلة وتاريخها وSHA؛ احتفظ بلقطة مستقلة في snapshots/.
3. شغّل python scripts/update_dashboard.py وراجع الناتج والروابط.
4. اكتب تقرير الفرق وحدّث clients/up، ثم commit على update مع expected SHA دون force.

لا يوجد تحديث تلقائي أو مهمة مجدولة أُنشئت بهذا الإعداد. رسالة العميل جاهزة لإرسالها في جلسة جديدة. اللوحة لا تثبت الجاهزية ولا تتحكم بالعملاء.
