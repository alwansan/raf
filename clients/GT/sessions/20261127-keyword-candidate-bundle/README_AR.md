# G3 — strict candidate-only Unity Android Vulkan bundle join

New separate gate recomputes the candidate plan and binds actual candidate SHA, source packet, route packet, scope proof and named pass coordinates to a Unity receipt. It requires actual compiler callback PassType/stage/platform and complete active key sets, observed shader.keywordSpace isOverridable scope, exact serialized source LightMode and pass name, every decoded VS/FS module and its identity. Unknown active names, extra unproved table names, separate keyword lanes, wrong/missing stage, ambiguity and source-ref module drift reject. Actual combined table allowed only if every row contains both stages. Original use requires separately established stage SHA commitments and matching source flags; the authored mode instead independently checks route-specific markers in decoded SPIR-V. No source flags are inferred from authored flags, no permission/installation, no original runtime acceptance. Fixed macros and unnamed/ambiguous passes remain blocked in this gate until specifically proven.

Disposable authored fixture uses the existing planner and emitter (one named Always/Normal pass, four mixed local/global routes, eight stage markers). Actual Unity 2021.3.45f2 Android Vulkan AssetBundle, IPreprocessShaders observations and material API toggle/restore; independent UnityPy reader and pinned smol-v decoder, spirv-val Vulkan1.1 and disassembly. No original source or original DXBC, no game Player or XAPK. 12 source-only tests plus prior 29 regressions. Actual execution pending. No legacy caller/installer changed. Original authorization A3 and G0–G6 remain open; white meshes/black fire priorities unchanged.
