# ملخص تقدم GT للمالك

آخر تحديث: تأسيس GT. **جرد اللعبة الشامل لم يُنفّذ بعد.** المعايرة السابقة أثبتت 6 مجسمات و7 مواضع مواد في المختبر. تُحتسب نتائج المشروع الرئيسي بعد مطابقة هوياتها وأدلتها.

| الفئة | الإجمالي من الجرد | مستعاد ومتحقق | مدمج في المشروع | مثبت في بناء Android | نسبة الدمج |
|---|---:|---:|---:|---:|---:|
| المجسمات/الميشات الفريدة | قيد الجرد | 0 | 0 | 0 | — |
| استعمالات Renderer/Submesh | قيد الجرد | 0 | 0 | 0 | — |
| المواد الفريدة | قيد الجرد | 0 | 0 | 0 | — |
| الخامات والصور الفريدة | قيد الجرد | 0 | 0 | 0 | — |
| الشيدرات الفريدة | قيد الجرد | 0 | 0 | 0 | — |
| Shader Pass/variants المطلوبة | قيد الجرد | 0 | 0 | 0 | — |
| Compute shaders/kernels الداخلة بالنطاق | قيد الجرد | 0 | 0 | 0 | — |
| الظلال والمؤثرات والارتباطات الرسومية | قيد الجرد | 0 | 0 | 0 | — |

الصفر هو عدد ما تحقّق منه GT في المشروع عند التأسيس. قد يكتشف الجرد أعمالًا مدمجة سابقًا. بعد تثبيت المقام، نسبة الدمج = المدمج ÷ الإجمالي × 100 لكل فئة. اعرض نسبة الإثبات في البناء عند وجود بناء، ولا تجمع فئات بوحدات مختلفة في نسبة واحدة.

حدّث عند كل دفعة: تاريخ، SHA المصدر والمشروع والبناء عند وجوده، تغطية الجرد، إضافات هذه الدورة، المتبقي وأسباب التعطل، وروابط الأدلة وActions. إذا تغيّر الإجمالي بسبب اكتشاف حاوية أو إزالة تكرار، سجّل الفرق والسبب.
