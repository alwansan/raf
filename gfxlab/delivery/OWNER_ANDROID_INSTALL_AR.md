# GFX142 — تثبيت APK الأصلي على أندرويد

## تنبيه مهم: ملف GitHub المشفّر ليس APK

مرفق GitHub Actions باسم `GFX142-ENCRYPTED-OWNER-DELIVERY-NO-PLAINTEXT` يحتوي ملفاً بالامتداد `.apk.cms`. هذا **تغليف مشفّر بخوارزمية AES-256-GCM** مخصص لنقل ملفات اللعبة الأصلية بأمان من GitHub العام، وليس ملف APK يستطيع أندرويد تثبيته، ولا يمكن تصحيح ذلك بتغيير الامتداد.

بعد تنزيل المرفق المشفّر، يجب فكّه بصورة موثوقة باستخدام مفتاح المستلم الخاص ثم التحقق من بصمة ملف APK الناتج؛ لا تنقل ملف `.cms` نفسه إلى مُثبت التطبيقات.

## نسخة GFX142 التي تم استردادها وتسليمها داخل محادثة المالك

تم بنجاح فك تشفير المرفق في بيئة المحادثة، ثم فحص APK المسترجع وإعطاؤه للمالك كملف مستقل باسم `GFX142-Install.apk`، وبنسخة بديلة `GFX142-Installable-APK.zip` بداخلها **APK غير مشفّر** وREADME عربي. روابط `sandbox:` خاصة بجلسة المحادثة وليست رابط GitHub عاماً، وقد لا تكون متاحة في الجلسات اللاحقة؛ تجنب اختراعها أو تكرارها دون التحقق منها.

## خطوات الهاتف

1. حمّل `GFX142-Install.apk` مباشرة من مرفق المحادثة، **ولا تثبّت** `*.apk.cms`.
2. إن استُخدم ZIP البديل، استخرج `GFX142-Install.apk` منه بواسطة ZArchiver، ثم ثبّته.
3. إذا رفض التحديث بسبب اختلاف التوقيع، أزل **فقط** النسخة القديمة من `com.alwansan.gfx124` ثم ثبّت الجديدة، دون حذف لعبة Raft.
4. افتح تطبيق GFX124؛ ينتج ملف `GFX124-ALL-TEST-LOGS-*.zip` في `/storage/emulated/0/Download/Games/cl/test/g/`.
5. ارفع **ملف السجل الناتج** إلى المحادثة لتحليل 9 حالات و51 لقطة مقارنة بمراجع Mesa في APK الصحيح.
